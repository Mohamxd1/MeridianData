# Support Inbox

## Goal

Stop support from living in your personal email.

## Minimum setup

Create:

```txt
support@usedataforge.com
```

Use one:

- Crisp
- Help Scout
- Intercom
- Front
- Gmail shared inbox

## Tags

- bug
- billing
- onboarding
- export-failure
- extraction-accuracy
- feature-request
- urgent-client

## First response template

Thanks for reaching out. I’m checking the affected workspace and job logs now.

Please send:
1. the client/workspace name
2. the approximate upload time
3. the file name or job ID
4. what you expected to happen
5. what actually happened
