# Status Page

## Goal

Give clients a public place to check if DataForge is down.

## Components

Create these components:

- API
- Frontend app
- File processing workers
- Exports
- Third-party AI providers

## Incidents

Use these statuses:

- Operational
- Degraded performance
- Partial outage
- Major outage
- Maintenance

## Client-facing copy

```txt
We are investigating elevated processing failures. Uploads are accepted, but some jobs may be delayed. Approved records and exports remain available.
```
