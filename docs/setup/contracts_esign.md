# E-sign Contracts

## Goal

Have a signed agreement before processing real client files.

## Tools

Use one:

- Dropbox Sign
- PandaDoc
- DocuSign
- Adobe Sign

## Documents to upload

- Service Agreement
- Privacy Policy acknowledgement
- Data Processing Agreement
- File Retention Policy
- SLA for Pro/Enterprise clients

## Signing workflow

1. Client accepts proposal.
2. Send service agreement + DPA.
3. Client signs.
4. You countersign.
5. Store signed PDF in your client folder.
6. Only then enable production workspace.
